This is a demo how we can upload our Delta Mini-Projects to our Git/Github handle as a repo
# master 
If our main branch's name is master then we have to change branch name by using:
"git branch -M main" (used to rename branch)
# Shortcuts
1. If even once in our code we write "git push -u origin main" then we don't have to write "origin main" from thenonwards we can simply write "git push"
2. If there is only a single file left to be added then we can skip the "git add filename" step & directly write commit step with add by : "git commit -am "Message" instead of "git commit -m "Message"
